## Описание работы сервиса
1. Получает запросы снаружи по gRPS и отдаёт соответствующие ответы.
2. В начале работы:
   * Подключается к яндекс диску.
   * Скачивает БД со списками файлов.
   * Создание JSON файла со списком источников и данных по ним. Файл хранится в памяти.
3. Ручки:
   * Дать список источников (тот самый JSON файл)
   * Дать ссылку по ID объекта и какое-то его описание
   * Сохранить на яндекс диск файл и описание для него
   * Обновить данные о содержимом библиотеки в БД
   * Отдать список регионов.
   * Создать новый регион для сохранения источников.
   * Отдать список групп для объектов.
   * Создать новую группу для объектов.
   * Отдать список объектов.
   * Создать новый тип объектов для источников.
   * Отдать копию файла БД.
   * Отдать описание сервиса Librarian.
   * Создать регион (для админа).
   * Создать период (для админа).
4. Типы хранимых объектов:
   * Книги/статьи/файлы - большие тексто-графические объекты
   * Статьи - средние тексто-графические объекты
   * Куски книг и статей - маленькие тексто-графические объекты
   * Карточнки объектов реконструкции
   * Фото объектов реконструкции
   * Ссылки на страницы URL
5. Структура для хранения на яндекс диске
   * Папка с книгами
   * Папка со статьями 
   * Папка с фрагментами
   * Папка с фото
   * Папка с карточками
   * Папка с JSON файлами для ссылок и описаний JSON (а надо ли?)
   * Папка с БД и JSON файлом из БД (а надо ли?)

## Структура базы данных

### Список таблиц

    - Источники (общая таблица)
    - Книги
    - Статьи
    - Фрагменты
    - Фото
    - Карточки (в разработке)
    - Источники (общая таблица)

    - Регионы (техническая таблица)
    - Века (техническая таблица)

#### Источники (sources)
| Столбец    | Описание                               |
|------------|----------------------------------------|
| id         | уникальный ID источника                |
| type       | тип источника (в какой папке)          |
| object_id  | ID источника в соответствующей таблице |
| address    | адрес источника на яндекс диске        |
| created_at | дата создания записи об источнике      |

#### Книги (books)
| Столбец      | Описание                                                      |
|--------------|---------------------------------------------------------------|
| id           | уникальный ID источника                                       |
| name_ru      | название книги на русском                                     |
| name_native  | название книги в оригинале или на английском                  |
| author_ru    | автор или авторы книги на русском, через запятую с инициалами |
| year         | год публикации                                                |
| regions      | регионы, через запятую                                        |
| time_periods | временные периоды/века, через запятую                         |
| description  | описание                                                      |
| file_format  | формат файла книги                                            |
